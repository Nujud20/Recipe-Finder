# Recipe Finder

## Overview
Recipe Finder is an academic team project focused on simplifying recipe discovery and ingredient management. The proposed application helps users find recipes based on available ingredients and provides features to support a more convenient cooking experience.

## Project Work
The project covered several stages of the software development process:

### 1. Requirements and Planning
- Problem definition
- User research and feedback analysis
- Feasibility study
- Project planning
- Functional and non-functional requirements
- Use case and system design diagrams

### 2. UI/UX Design
- Low-fidelity sketches
- High-fidelity prototype
- Ingredient selection screens
- Recipe browsing and filtering
- Step-by-step cooking instructions
- Portion size adjustment
- Ingredient expiry notifications

### 3. Website Development
- HTML page development
- CSS styling
- Multiple website pages
- W3C Markup Validation
- Responsive layout demonstrations

## Proposed Features
- Search for recipes using available ingredients
- Filter recipe suggestions
- Suggest alternative ingredients
- Adjust recipe quantities
- Save favorite recipes
- Rate and review recipes
- Provide cooking timers and instructions
- Send ingredient expiry reminders

## Project Type
Academic Team Project
